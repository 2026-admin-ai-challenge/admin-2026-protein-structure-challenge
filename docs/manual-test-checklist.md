# 수동 테스트 체크리스트

사람이 직접 눌러 보며 확인하는 목록입니다. ★는 자동 테스트로 확인하지 못해 **반드시 사람이 해 봐야 하는** 항목입니다.

- 접속 주소: `https://<NGROK_DOMAIN>` (ngrok으로 띄운 경우) 또는 `http://localhost:3000`
- 준비물: 관리자 계정, `accounts/participants.csv`의 팀 계정 2개 이상, `var/demo/` 폴더의 예제 ZIP 4개(`python scripts/make_demo.py`로 생성)
- 시작 조건: 관리자 화면에서 시작·종료 시각을 넣고 대회를 연 상태

| 예제 ZIP | 기대 결과 |
| --- | --- |
| `code.zip` | 완료, Public 점수 표시 |
| `code_mock_timeout.zip` | 실패, 시간 초과 (mock 평가기 전용) |
| `code_crash.zip` | 실패, 실행 오류 (Docker 평가기에서만. mock에서는 완료) |
| `code_bad_output.zip` | 실패, 출력 형식 오류 (Docker 평가기에서만. mock에서는 완료) |

## 1. 접속과 로그인

- [ ] ★ 처음 접속 시 ngrok 안내 페이지에서 "Visit Site"를 누르면 사이트가 열린다
- [ ] ★ 다른 사람의 컴퓨터·다른 네트워크(휴대폰 데이터)에서도 열린다
- [ ] 배부받은 아이디·비밀번호로 로그인되고, 오른쪽 위에 팀 이름이 보인다
- [ ] 아이디를 대문자로 쳐도 로그인된다
- [ ] 틀린 비밀번호는 "아이디 또는 비밀번호를 확인하세요"로 거절된다
- [ ] 회원가입 버튼이나 링크가 어디에도 없다
- [ ] 로그아웃 후 Submit 탭이 로그인 안내로 바뀐다

## 2. 제출 (참가자)

- [ ] ★ "Browse files"로 `code.zip`을 골라 제출하면 확인 창 → 접수 ID → 남은 횟수가 차례로 나온다
- [ ] ★ 파일을 끌어다 놓아도(drag & drop) 선택된다
- [ ] 새로고침 없이 상태가 "대기 중 → 채점 중 → 완료"로 바뀌고 점수가 표시된다
- [ ] `.zip`이 아닌 파일은 선택 단계에서 거절된다
- [ ] 폴더째 압축한 ZIP은 "최상위에 필수 항목이 없습니다" 안내와 함께 거절되고 횟수가 줄지 않는다
- [ ] `train.py`를 뺀 ZIP도 같은 안내(필수 항목: train.py)로 거절되고 횟수가 줄지 않는다
- [ ] `code_mock_timeout.zip`은 "실패"와 시간 초과 안내가 나온다
- [ ] ★ 수십~수백 MB ZIP을 올릴 때 진행률이 움직이고 끝까지 접수된다 (ngrok 통과 여부는 미확인)
- [ ] 화면을 닫았다 다시 열어도 제출 내역이 남아 있다

## 3. 팀 제한

- [ ] 같은 팀 계정을 두 브라우저에서 열면 제출 내역과 남은 횟수가 똑같이 보인다
- [ ] 20회를 다 쓰면 제출 버튼이 막히고 안내가 나온다 (관리자가 한도를 2~3으로 낮춰 놓고 해 보면 빠르다)
- [ ] 다른 팀 계정에서는 그 팀의 제출 내역이 보이지 않는다

## 4. 리더보드

- [ ] 채점이 끝나면 Leaderboard와 Overview의 순위에 팀이 나타난다
- [ ] 같은 팀이 더 높은 점수를 내면 그 점수로 바뀌고, 낮은 점수를 내면 그대로다
- [ ] "Final"은 잠금 표시로 보이고 열리지 않는다
- [ ] mock 채점 안내 문구가 Submit과 Leaderboard에 보인다 (mock 평가기일 때)

## 5. 관리자 화면

- [ ] 일정·횟수 저장, 대회 열기/닫기가 되고 참가자 화면에 바로 반영된다
- [ ] 팀을 만들고 "랜덤 아이디로 발급"하면 임시 비밀번호가 한 번 표시되고, 그 계정으로 로그인된다
- [ ] 비밀번호 재설정 후 예전 비밀번호로는 로그인되지 않고, 로그인돼 있던 창도 풀린다
- [ ] 차단한 계정은 로그인되지 않고, 그 팀이 순위에서 빠진다
- [ ] "제출·대기열"에서 상태·실패 사유 필터와 검색이 동작한다
- [ ] 실패한 제출의 "로그", "다시 채점", "횟수 복구"가 동작한다
- [ ] ★ "ZIP 받기"로 내려받은 파일이 참가자가 올린 ZIP과 같다 (압축을 풀어 확인)
- [ ] "파일 삭제"는 사유를 적어야 진행되고, 삭제 후 "파일 삭제됨"으로 표시되며 점수는 남는다
- [ ] 순위에 반영된 제출("순위 반영")과 채점 중인 제출은 "파일 삭제"가 막혀 있다
- [ ] "파일 정합성 검사"가 "일치합니다"로 나온다
- [ ] "팀·계정"에 팀별 ZIP 개수와 용량이 표시된다
- [ ] "조작 기록"에 방금 한 조작이 담당자·시각과 함께 남는다
- [ ] 참가자 계정으로 `/admin` 주소에 들어가면 관리자 메뉴가 열리지 않는다

## 6. 종료 절차

- [ ] "Freeze leaderboard" 후 새 점수가 순위에 반영되지 않고, 해제하면 반영된다
- [ ] 종료 시각이 지나거나 대회를 닫으면 제출이 막힌다
- [ ] 대기 중인 제출이 있으면 "Publish final leaderboard"가 거절된다
- [ ] 최종 공개 후 Final 순위가 열린다. **되돌릴 수 없으니 맨 마지막에, 버려도 되는 DB에서만 한다**

## 7. 화면과 문구

- [ ] ★ 휴대폰에서 메인, Submit, 관리자 화면이 깨지지 않는다
- [ ] ★ 다크 모드(달 아이콘)에서 글자가 잘 보인다
- [ ] ★ Overview, Data, Evaluation, Rules의 문구가 운영진이 공지할 내용과 맞는다
- [ ] 화면 어디에도 "CSV", "2 MB", "하루 5회", "UTC 초기화"가 남아 있지 않다

## 8. 장애 상황 (승현 담당)

- [ ] 채점 중에 `docker compose restart worker`를 해도 그 제출이 다시 채점된다
- [ ] ★ 컴퓨터를 재부팅한 뒤 사이트와 대기열이 그대로 살아난다
- [ ] ★ 컴퓨터가 절전에 들어가면 접속이 끊기는지 확인하고, 절전을 꺼 둔다

- 무엇이 나왔는지 (가능하면 화면 캡처)
