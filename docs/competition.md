# 참가자 안내

> 운영진 확정 전인 규칙은 "추후 공지"로 표시했습니다. 공지 전에는 이 문서를 참가자 규정으로 게시하지 마세요.

## 무엇을 하는 대회인가

단백질 도메인의 관측 서열과 제공된 3D 구조(Cα 좌표)로 CATH Architecture를 분류하는 모델을 만듭니다. 평가는 Macro F1입니다.

## 참가 순서

1. **로그인**: 운영진이 배부한 팀 아이디와 임시 비밀번호로 로그인합니다. 회원가입은 없습니다. 비밀번호를 잊었다면 운영진에게 재설정을 요청하세요.
2. **데이터 받기**: 대회 시작 시각부터 Data 탭에서 학습 데이터를 받습니다. 학습 서열·정답, 31개 기본 특징, 학습 내부 검증 분할, 선택 활용 자료인 3D 좌표가 있습니다. **평가 데이터는 제공하지 않습니다.**
3. **학습**: 제공된 학습 데이터로 자기 컴퓨터에서 모델을 학습하고 저장합니다. 3D 좌표를 쓰지 않고 31개 특징만 써도 됩니다.
4. **제출**: 학습된 모델과 추론 코드를 ZIP 하나로 묶어 Submit 탭에 올립니다. 접수 ID를 받고 채점 대기열에 들어갑니다.
5. **결과 확인**: 채점이 끝나면 팀 제출 내역에 Public 점수 또는 실패 사유가 표시됩니다. 팀의 최고 Public 점수가 리더보드에 반영됩니다.

## 제출 ZIP

```text
code.zip
├── inference.py        필수
├── train.py            필수 (채점 때 실행하지 않음)
├── requirements.txt    필수 (채점 전에 설치할 패키지)
└── model/              필수 (학습된 가중치, 전처리 객체)
```

- 필수 항목이 ZIP **최상위**에 있어야 합니다. 폴더를 통째로 압축하면 한 단계 안쪽에 들어가 접수되지 않습니다. 파일과 `model` 폴더를 직접 선택해 압축하세요. `train.py`가 빠진 ZIP도 접수되지 않습니다(횟수는 차감되지 않음).
- 압축 ZIP은 최대 500 MB, 추론은 최대 10분입니다.
- 채점 환경에는 기본 패키지(numpy, pandas, scipy, scikit-learn, joblib, torch, transformers, plotly, matplotlib, pyarrow, SQLAlchemy, catboost)만 설치되어 있습니다. `requirements.txt`에 적은 패키지는 **추론 직전에 적은 버전대로 설치**합니다. 기본 패키지는 적은 조건(`transformers>=5` 등)을 기본 버전이 만족하면 그대로 쓰고, 만족하지 않는 버전을 적으면 그 버전을 새로 설치합니다. 기본 패키지도 `requirements.txt`에 적어 두는 것을 권장합니다. 대회 패키지 목록(89개)의 버전은 서버에 미리 받아 두어 빠르게 설치되고, 그 밖의 패키지나 버전은 PyPI에서 받습니다. 설치 시간은 추론 10분에 포함되지 않습니다.
- **추론 중에는 학습과 인터넷 접속을 할 수 없습니다.** 필요한 패키지는 모두 `requirements.txt`에 적어야 합니다.
- PyPI에 **Linux·Python 3.12용 wheel이 있는 패키지만** 설치할 수 있습니다(소스 빌드 불가). 설치하지 못하면 "패키지 설치 실패"로 채점이 끝나고 횟수가 차감됩니다. GPU용 torch(`torch==2.14.1+cu128`)는 같은 버전의 CPU 빌드로 설치합니다.
- `-r`, `-e`, 파일 경로, URL은 쓸 수 없어 ZIP을 받는 즉시 거절합니다(횟수 차감 없음). `--extra-index-url` 같은 인덱스 옵션과 `--hash`는 무시합니다. PowerShell에서 `pip freeze > requirements.txt`로 만든 UTF-16 파일도 읽습니다.
- 추론 코드의 실행 명령과 입력·출력 형식은 베이스라인과 함께 공지합니다.

## 제출 횟수


대회 전체 기간에 **팀당 최대 20회**입니다. 팀의 모든 계정이 함께 쓰며 날짜가 바뀌어도 초기화되지 않습니다. 접수 단계에서 거절된 업로드는 횟수를 쓰지 않습니다. 접수 후에도 ZIP 규격 위반과 서버 오류는 차감하지 않습니다. 예측 출력 형식 오류·실행 오류·시간 초과·메모리 초과·패키지 설치 실패 등 나머지 채점 실패는 제출 횟수 1회를 차감합니다. 서버 오류로 실패한 제출은 운영진이 원인을 해결한 뒤 다시 채점합니다.

## 실패했을 때

| 표시 | 뜻 | 확인할 것 |
| --- | --- | --- |
| ZIP 규격 위반 | 압축 내용이 규격과 다름 | 최상위 필수 항목, 경로, 링크 파일, `requirements.txt`의 `-r`·`-e`·경로·URL |
| 패키지 설치 실패 | `requirements.txt`의 패키지를 설치하지 못함 | 표시된 pip 오류, 패키지 이름·버전, Linux용 wheel 유무 |
| 실행 오류 | 추론 코드가 오류로 종료 | 같은 명령을 내 컴퓨터에서 실행, `requirements.txt`에 빠뜨린 패키지 |
| 시간 초과 | 10분 안에 끝나지 않음 | 모델·전처리 경량화 |
| 메모리 초과 | 메모리 한도 초과 | batch 크기, 모델 크기 |
| 출력 없음·형식 오류 | 예측 파일이 없거나 형식이 다름 | 출력 경로, `id,label` 컬럼, 행 수, 라벨 값 |
| 서버 오류 | 채점 서버 문제 | 조치 불필요. 운영진이 다시 채점 |

## 규칙

- 운영진이 제공한 학습 데이터로만 학습합니다. 외부 사전학습 가중치와 외부 데이터는 사용할 수 없습니다. 채점 중에는 네트워크가 차단됩니다.
- CATH/PDB 조회, 서열·구조 유사도 검색, 원본 domain ID 복원으로 평가 정답을 찾는 행위와 수작업 label 작성을 금지합니다.
- 계정 공유, 다른 팀과의 모델·비공개 코드 공유, 여러 계정으로 제출 제한을 우회하는 행위를 금지합니다.
- 수상 후보는 학습 코드와 재현에 필요한 설정을 제출합니다. 제공 데이터만으로 결과를 재현할 수 없거나 규칙 위반이 확인되면 실격될 수 있습니다.
- 최종 순위는 팀에서 Public 점수가 가장 높았던 제출물 1개의 Private 점수로 정합니다. 최종 제출물은 자동으로 정해지며, 다른 제출물의 Private 점수가 더 높아도 바뀌지 않습니다.
- 점수가 같으면 제출한 ZIP 파일이 더 작은 쪽, 크기도 같으면 먼저 제출한 쪽이 앞섭니다. 팀 안에서 최종 제출물을 고를 때도 같은 기준을 씁니다.
- 순위 동결 시점은 추후 공지합니다.
